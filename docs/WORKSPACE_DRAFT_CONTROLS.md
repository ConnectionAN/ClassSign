# 工作區與草稿操作修正（v1.1.3）

- 同帳號重複收到登入通知時，只重新驗證帳號狀態，不卸載工作區。停用、登出或換帳號仍會清除原工作區。頁面與選取學生按登入帳號保存在目前分頁，重新整理後仍可回到原頁。
- 「＋ 自訂費用」依使用者偏好放回選取學費袋的明細下方，僅草稿可新增，費用直接加入目前這張學費袋。
- 草稿的每筆課程費、教材費、自訂費用旁有「刪除費用」，重算不會加回。可在「已刪除費用（可還原）」恢復項目。刪除只影響該張草稿，教材仍可於其他學費袋列帳，既有課程與簽到不變。自動抵扣／反向調整仍透過原課程處理。
- 學生資料夾新增「編輯學生姓名」，沿用原學生 UUID，保留課表、簽到及帳務關聯。草稿同步更新姓名，已開立學費袋保留當時姓名。併發改名以 expectedName 防止覆蓋他人更新，並記錄經手帳號與新舊姓名。
- 首頁 HTML 不儲存快取，頁尾顯示版本 v1.1.3，方便確認已載入新版本。已開著舊程式的分頁仍需重新載入一次。

部署：先套用 `20261031143934_draft_item_controls_student_rename.sql`，再發布前端。新表只有工作室成員可讀，寫入走原本交易函式與工作室鎖；原私有函式禁止直接執行。遷移本身不重算既有帳單，不改姓名或簽到資料。正式測試以交易回滾，不留下測試費用或改名。
