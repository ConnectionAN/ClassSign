## 斷點實測

- 手機：375×768、390×768；登入另採高度 844。原觸控回歸另包含 320／430px。
- iPad：768×1024、1024×768。展開側欄時週欄最小 100px，在課表內橫向捲動；收合時保留七欄容納與日欄獨立捲動。
- 桌面：1440×768。學生列表與詳情仍獨立捲動，主頁面不被詳情捲動帶走。
- 本版接受經授權的排版／尺寸差異，不沿用 v1.4「幾何完全一致」判定。

## 真實瀏覽器證據

已在 Chromium 中分別載入原 main、v1.4、v1.4.1 React 頁面；使用同一固定日期及模擬學生／課程資料。每版五種尺寸，涵蓋登入、預設課表、日、週、雙簽、學生列表、詳情及備註，共 40 組主要畫面。Before 並非 AI 圖或設計稿；After 亦由實際元件渲染。視窗 PNG 與長頁 -full.png 分開保存。

主輸出：outputs/visual-v141/{before-main,before-v14,after}。ClassSign-v1.4.1-compare.html 可切換頁面、尺寸與基準；長頁檔案用於檢查畫面外內容。

## 共用元件

src/UI.tsx 提供 Button、SectionHeading、StatusBadge、MetricCard、StudentIdentity、StudentListItem、SegmentedControl、LessonCard、CalendarDayHeading。元件只接收原資料及 callback，沒有 API、帳務或排課 state。詳見 UI_SYSTEM.md 及 UI_LAYOUTS.md。
