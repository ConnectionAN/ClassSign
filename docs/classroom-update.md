# 鋼琴課小幫手：課表與學生資料更新

- 日／週課表、課程詳情、待補課及補課表單不再顯示學費。
- 功能列可收合／展開並記住本裝置的選擇。收合時回到課表，其他功能入口隱藏。此為版面收合，並非密碼鎖。
- 平板直向 768×1024、橫向 1024×768 在收合後同時顯示七日；課程較多時，各日期欄可向下捲動。
- 系統名稱改為鋼琴課小幫手；兩個頁面標題改用「學習」。
- 學生備註最多 4000 字，儲存在共用工作室；若另一位老師已更新相同備註，拒絕覆寫並要求重新整理。
- 學生依目前有效的固定時段，按週一至週日、時間排序。尚未生效的時段在生效後改變排序；沒有有效時段則採最近一組將生效時段，無任何時段者置後。
- 課表新增單堂簽到：選學生、日期、開始時間、課程長度後雙簽，一次儲存課程與簽名。不建立每週循環。伺服器使用學生目前學費，畫面不顯示金額；檢查時段衝突、封存／停用、未來日期與重複送出。

## 部署與驗證

先套用 `20261031134131_student_notes_oneoff.sql`，再部署前端。既有工作室 owner、Auth UUID、授權、歷史課程與金額保持原值。Google/Supabase/Cloudflare 的憑證與網域設定不需改動。

驗證：41 項資料／登入測試、18 項瀏覽器測試、正式設定的 TypeScript／Vite 建置通過；另驗證平板七欄不溢出視窗。正式資料庫以交易回滾測試備註與單堂雙簽／重送，未留下測試學生。安全檢查沒有新增項目。
