# 自訂費用負數扣除

基準 main：479974e8fe26f6fc41327501cf8ea69e1d6e7575。
分支：billing/negative-custom-fees。未合併、未部署或套用正式資料庫。

## 使用方式
選擇本月學費袋草稿，開啟「＋ 自訂費用」，名稱例如「10月請假不補課扣除」，金額填 -800，備註原學費已收、確定不補課且尚未扣除。明細顯示扣除標籤與負號，減少本期應收，列印同樣保留。正數仍為增加費用。

只允許非零整數，範圍正負100,000,000。學費袋合計可為0，不能為負數。扣除只影響本期，不建立自動結轉抵扣餘額。已由一般請假抵扣處理的課程，不要重複手動新增。會補課時保留原學費；不補課時沿用現有請假抵扣，不增加歷史補登功能。
