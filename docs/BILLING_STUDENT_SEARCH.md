# 學費袋學生排序與關鍵字建議

基準 main：2b9cdef5ba6764a3f220736fffadcb6730f9bc44。
分支：billing/student-order-search。未合併、未部署正式站，不需資料庫更新。

## 行為
- 產生／重算草稿的學生下拉選單，沿用學生資料夾的studentOrder排序：週一至週日、同日依固定上課時間；無時段者依既有規則置後，封存學生仍不列入開立選單。排序基準與學生資料夾相同，採目前有效課表，不因收費月份改變規則。
- 搜尋欄輸入姓名任意位置的關鍵字，在下方列出建議。例如「王」匹配「王小安」「李王明」「林小王」。忽略前後空白、英文大小寫及全半形差異，不做拼音或模糊猜測。
- 建議沿用課表排序，封存／歷史學生另加標示。可查找尚未開立本期學費袋的學生；沒有本期袋時仍顯示原有空資料提示。
- 點選或上下方向鍵＋Enter選取後，依學生ID篩選，避免同名混淆；清空輸入恢復原有月份／狀態篩選。Escape、離開搜尋欄會關閉建議；中文輸入法組字中的Enter不選取。
- 原學費袋姓名快照與目前姓名皆可用文字查詢；選取目前姓名時用ID找到更名前的舊袋。只篩選資料，不自動產生、開立或更動帳務。

## 修改
Studio.tsx將既有orderedStudents傳給學費袋頁，不複製另一套排序。Billing.tsx新增可鍵盤操作的combobox與建議清單；billingStudentSearch.ts為純前端姓名比對。visual-refresh.css只加入學費袋搜尋區樣式。無Supabase、migration、費率、金額或收款邏輯變更。
